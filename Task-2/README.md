# SWYNEX Task 2 - Exploratory Data Analysis (EDA)

## Objective
To analyze the cleaned customer data from Task 1 and create charts and a dashboard to find insights about customers.

## File Included
- Clean_data.xlsx - Cleaned data + Pivot + Dashboard Charts + Insights

## Dashboard - 5 Charts

### 1. Country Distribution - Customer by Country
- USA: 57%
- UK: 43%
- Insight: Most customers are from USA.

### 2. Age Group - Customers by Age Group
- Highest customers in age group 28-37 (1079) and 48-57 (1039)
- Lowest in age group 88-97 (213)
- Insight: Most customers are young to middle-aged (18-67).

### 3. Status - Active Vs Inactive
- Active: 7895
- Inactive: 1318
- Insight: Majority of customers are Active, only ~14% are Inactive.

### 4. Region - Customers by Region
- North: 9024
- South: 189
- Insight: Almost all customers are from North region.

### 5. Month Wise Signups - Signups Per Month
- Highest signups in June (843) and March (833)
- Lowest in December (445)
- Insight: Signups are stable Jan to Nov, but drop in December.

## Key Insights
1. USA customers are more than UK.
2. North region dominates with 9024 customers.
3. 86% customers are Active.
4. Most customers are in 28-57 age group.
5. December has lowest new signups.

## Tools Used
- MS Excel
- Pivot Table & Charts
