# SWYNEX - Task 1: Data Cleaning & Preparation

## Project Overview
This project is a part of my Data Analytics Internship at SWYNEX Technologies.
In Task 1, I cleaned a messy dataset using Excel and made it ready for analysis.

## Dataset
- Original File: Raw Dataset
- Cleaned File: clean_data.xlsx

## Tools Used
- Microsoft Excel

## Cleaning Steps Performed
1. Removed duplicate rows
2. Handled missing / blank values
3. Removed extra spaces using TRIM function
4. Fixed date and number formats
5. Corrected spelling mistakes
6. Removed unnecessary columns
7. Checked data types for all columns

## Files in this Repository
- clean_data.xlsx - Final cleaned dataset
- README.md - Project documentation

## Key Learnings
- Importance of clean data before analysis
- How to handle missing and duplicate data in Excel
- How to fix formats and errors in real data
